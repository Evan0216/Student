FAQs

How can I redeem my TrainPal student discount?

To redeem your discount:
Verify your student status via Student Beans.
Obtain the unique promo code provided.
Apply the code during checkout on the TrainPal website or app.
Note: Each promo code is valid for a single use per account and cannot be combined with other offers.

What should I do if my student discount code isn't working?

If you encounter issues:
Ensure the promo code hasn't expired. Confirm you've entered the code correctly. Verify that your student status is confirmed via Student Beans. Remember, each code is valid for a single use per account and device.

Is the TrainPal student discount applicable to all train services?

The student discount applies to train fares across the UK and Europe. However, it's always advisable to check specific terms and conditions for any exclusions. Time to book your next student holiday destination!
